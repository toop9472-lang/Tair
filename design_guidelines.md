# طير Design Guidelines

## 🎨 Color Palette (extracted from logo)

### Primary Colors
- **Mint Cyan** (background base): `#c8fce6` → `#a7f3d0`
- **Aqua Cyan**: `#67e8f9` → `#22d3ee`
- **Fresh Green**: `#84cc16` → `#65a30d`
- **Sunny Yellow** (accent): `#fde047` → `#facc15`

### Bird Palette (secondary accents)
- **Parrot Red**: `#ef4444`
- **Canary Yellow**: `#f59e0b`
- **Bluebird**: `#3b82f6`
- **Lovebird Green**: `#22c55e`
- **Sparrow Orange**: `#f97316`

### Neutral
- **Text Primary**: `#0f172a` (deep slate)
- **Text Secondary**: `#475569`
- **Card Surface**: `#ffffff`
- **Card Border**: `#e2e8f0`
- **Muted BG**: `#f8fafc`

### Gradients (from logo)
- **Hero gradient**: `linear-gradient(135deg, #c8fce6 0%, #a7f3d0 50%, #7dd3fc 100%)`
- **CTA gradient**: `linear-gradient(135deg, #22c55e 0%, #06b6d4 100%)`
- **Text gradient** (طير logo style): `linear-gradient(135deg, #84cc16 0%, #22c55e 50%, #f59e0b 100%)`

## 📝 Typography

- **Arabic**: `Tajawal` (headers), `IBM Plex Sans Arabic` (body)
- **Latin**: `Inter` (body), `Cal Sans` (display)

### Sizes
- H1 hero: 32px, weight 800
- H2: 24px, weight 700
- H3: 20px, weight 700
- Body: 15px, weight 400
- Small: 13px, weight 500
- Caption: 11px, weight 500

## 🔘 Component Rules

- **Buttons**: 44+ pt height (accessibility for elderly carriers)
- **Border radius**: 16px cards, 999px pills, 20px CTAs
- **Shadows**: soft `0 4px 20px rgba(15, 23, 42, 0.08)`
- **Icons**: Lucide/Ionicons only — no emojis
- **RTL**: full RTL support, mirror layouts naturally

## 🐦 App Personality
- **Warm, trustworthy, family-friendly**
- Playful cartoon touches (bird illustrations)
- Not childish — must appeal to breeders + shop owners + elderly carriers
- Trust indicators everywhere: verified badges, ratings, review counts
